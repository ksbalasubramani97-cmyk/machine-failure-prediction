# Machine Failure Prediction System

## 📌 Project Overview
The Machine Failure Prediction System is a Machine Learning project developed using Python to predict potential machine failures from input data. It includes data preprocessing, model training, model comparison, and performance evaluation.

## 🎯 Project Objectives
- Analyze machine-related data.
- Prepare data for Machine Learning.
- Train and compare classification models.
- Evaluate model performance using standard metrics.
- Provide a foundation for predicting potential machine failures.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- XGBoost
- Joblib

## 🤖 Machine Learning Models
- Logistic Regression
- Random Forest
- XGBoost

## 📂 Project Structure
- `app.py` — Streamlit application.
- `coding.ipynb` — Jupyter Notebook containing project code.
- `machine_failure_prediction_dataset.csv` — Dataset used for model development.
- `models/` — Saved models and related output files.
- `model_comparison.csv` — Model comparison results.
- `test_predictions.csv` — Test prediction results.

## ⚙️ Key Steps
1. Data loading and exploration.
2. Data preprocessing and missing-value handling.
3. Feature scaling and categorical encoding.
4. Model training and comparison.
5. Model evaluation.
6. Prediction using the trained model.

## 📊 Evaluation Metrics
The project uses or considers the following metrics:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## 🚀 How to Run

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd machine-failure-prediction
```

### 2. Install dependencies
```bash
pip install pandas numpy scikit-learn matplotlib seaborn streamlit xgboost joblib
```

### 3. Run the Streamlit application
```bash
streamlit run app.py
```

### 4. Explore the notebook
Open `coding.ipynb` in Jupyter Notebook to review the analysis and model training workflow.
